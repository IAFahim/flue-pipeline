# flue-pipeline

Bare-minimum N-step agent pipeline on [Flue](https://flueframework.com).

## How it works

```
src/
  pipeline.ts              ordered list of skill references (the pipeline)
  skills/echo/SKILL.md     one step: takes input, returns { output }
  agents/pipeline-runner   createAgent() with model + pipeline skills
  workflows/run-pipeline   folds session over the pipeline
```

The workflow loops through `pipeline`, calling `session.skill()` on each step.
Each skill receives `{ input }` and must return `{ output: string }`.
The output of step N becomes the input of step N+1.

## Setup

```sh
npm install
cp .env.example .env    # paste your MiniMax API key
```

## Run

```sh
npx flue run run-pipeline --target node --payload '{"input":"hello world"}'
```

## Track-task workflow (DOTS Timeline mastery experts)

`src/workflows/track-task.ts` routes a designer request to a trained track
specialist (one MiniMax agent per DOTS Timeline track family), gets back
`{ code, explanation }` via the `track-task` skill contract, and executes the
C# raw through `unity-cli exec` (no SubScene wrapping — the mastery recipes
bracket scenes themselves).

> **Migration in progress.** The mechanical ~65 % of every mastery recipe (the
> SubScene bracket, director binding, field writes, verification, undo) is
> moving into deterministic `vex` editor tools — `unity-cli timeline_create`,
> `clip_add`, `director_bind`, `timeline_verify`, … As those land, the
> track-task workflow prefers a tool call over raw `exec`; `exec` stays the
> fallback for what no tool covers yet, and undo becomes a tool output instead
> of a second model pass. The tool design lives in the sibling
> `../unity-cli-tooling/` corpus; the C# in the BovineLabs packages' `.Editor`
> assemblies.

Payload:

```json
{ "track": "unity-track-transform-position", "request": "move the actor to (3,0,0) over 2s", "context": "optional scene JSON" }
```

Unknown `track` returns `{ ok: false, error: "unknown track", available: [...] }`.

## Add a step

1. Create `src/skills/<name>/SKILL.md` with name/description frontmatter
2. Import it in `pipeline.ts` and add to the array

That's it. Removing a step is deleting the folder and the import line.
